Privacy Policy

Leafy Discord bot · Last updated: October 2026

Overview

This is the privacy policy for the Leafy Discord bot (Application ID: 1457391730805702688). It explains what information the bot handles, what it saves, and how that information is removed.

What data we process

Leafy processes the following information strictly in real time to manage dynamic temporary voice channels and staff voice moderation:

  • Server IDs
  • User IDs
  • Voice state updates (for example, joining, leaving, or moving between voice channels)

No message content is permanently stored or tracked.

What data we store

Leafy saves only the minimal operational data it needs to work. This data is kept in local files and consists of:

  • Active voice-mute countdown timestamps and the user IDs they apply to
  • Owner IDs for temporary voice channels

Retention and deletion

  • Voice-mute records are deleted automatically when the timer finishes.
  • Temporary voice channel data is deleted when the channel is deleted.
  • Server data is deleted if the bot is removed from the server.

If you would like your data deleted immediately, contact the developer on Discord at Leafy#1758 and ask for a manual deletion.
